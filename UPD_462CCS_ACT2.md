**[LAB ACTIVITY - 2 (1.5 Marks)]{.underline}**

The file foodtruck.xlsx contains the dataset for our simple linear
regression problem. The first column is the population of a city and the
second column is the profit of a food truck in that city. A negative
value for profit indicates a loss.

In this part of the Lab, you will implement linear regression with one
variable to predict profits for a food truck.

**Requirements:**

1.  Data visualization

2.  Compute the parameters of the optimal Linear regression model

> w_opt, b_opt, SS_res, SS_total and R2

3\. Evaluate the Model using LR_Eval

4\. Subplot the data and the computed LR model
